# Screen List

Admin is one actor; HDT/UBND denote subtypes. Screen Specs continue to reference the existing PNG mockups, which are outside this consistency revision. Change Password is a panel on ACC129, not a new screen.

| Actor | Function | Screen ID | Screen name | Screen Overview | Priority |
|---|---|---|---|---|---|
| All Actors | Authentication | AUT009 | Login | Shared login screen for Tour Agency, Local Provider, UBND, and HDT. Guests are redirected here when attempting a restricted action. | Must |
| All Authenticated Users | Authentication | AUT026 | Logout Confirmation | Confirmation dialog before ending the current session. | Must |
| All Actors | Password Management | PAS011 | Enter Registered Email  | User enters their registered email address to request a password reset link. Form includes: Email input field, "Send Reset Link" button, "Back to Login" link. | Must |
| All Actors | Password Management | PAS014 | Check Your Email | Confirmation screen after email submission. Message: "We've sent a password reset link to your email. Please check your inbox and follow the link within 15 minutes. Didn't receive it? Check spam or request a new link." Includes: "Resend Link" button, "Back to Login" link. | Must |
| All Actors | Password Management | PAS142 | Set New Password | User clicks reset link from email and lands here. Form includes: New Password field (with complexity requirements visible), Confirm Password field, "Update Password" button, "Back to Login" link. Validates: Password complexity, passwords match. | Must |
| All Actors | Password Management | PAS143 | Password Updated | Success confirmation screen. Message: "Your password has been updated successfully. You can now log in with your new password." Includes: "Go to Login" button (primary CTA), "Back to Home" link (if authenticated). | Must |
| Guest | Registration | REG003 | Agency Registration | Agency creates an account and submits company/legal information for HDT verification. Registration is available only to Tour Agencies. | Must |
| Guest | Registration | REG115 | OTP Verification Input | Agency enters the OTP sent to the email address provided during registration as part of the registration and verification process. | Must |
| Guest | Registration | REG116 | Registration Status | Displays the Agency registration status, Pending Approval after verified registration; shows requested changes and a secure edit/resubmit action when HDT requests more information; subsequent review uses Approved/Rejected, without conflating Provider verification. | Must |
| Admin (HDT / UBND) | Admin Management | ADM079 | Admin Dashboard | Provides an operational overview of Agencies, Local Providers, bookings, collaborations, account activity, and key platform metrics within the Admin's data scope. | Must |
| Admin (HDT / UBND) | Admin Management | ADM095 | User Management | Manages user accounts, including account creation, enable/disable, viewing, and credential reset within the Admin's data scope. | Must |
| Admin (HDT / UBND) | Admin Management | ADM117 | Create Account | Admins can create accounts within their permission scope. HDT creates Admin subtype UBND; only UBND creates Local Provider accounts, within its one assigned village. Responsibilities and data access follow the associated actor and administrative scope. | Must |
| Admin (HDT / UBND) | Admin Management | ADM118 | Account Information & Access Actions | Shows permitted disable/enable/reset-password actions plus system-level account information such as account ID, role, status, registration date, and last login. | Must |
| Admin (HDT / UBND) | Admin Management | ADM145 | View Submitted Profile | Displays the submitted profile information of the selected account for review, including the submitted business/profile details and verification-related information. | Must |
| Admin (HDT / UBND) | Verification | VER146 | View Submitted Profile | Displays the submitted profile and supporting information required for the Admin to review Agency registration/legal change or Provider profile revision according to subtype, without conflating account activation and profile verification. | Must |
| Admin (HDT / UBND) | Verification | VER119 | Account Information | Displays system-level account information such as account ID, role, status, registration date, and last login for verification reference. | Must |
| Tour Agency | Explore | EXP017 | Explore | Main discovery screen after Agency login. Displays verified Village/Experience cards through browsing sections. The search bar opens AI Tour Matching directly. User behavior within the session is recorded to update preferences and re-rank recommendations. | Must |
| Guest | Explore | EXP120 | Public Explore | Public discovery screen for Guests. Shows only basic publicly available Village/Experience information. Price and contact details are hidden; public capacity and availability summary remain visible. Search and restricted actions redirect to Login. | Must |
| Tour Agency | AI Tour Matching | AIT121 | AI Tour Matching | Single chat-based matching screen. Agency describes its tour needs in natural language; AI analyzes and refines the requirements and returns matching Villages/Experiences directly within the conversation. The Agency can continue refining or open details/chat from result cards. | Must |
| Tour Agency | Discovery | DSC122 | Provider Profile | Agency views the Local Provider profile, including permitted business information, Village affiliation, Experiences, and relevant collaboration information. View-only. | Must |
| Guest | Discovery | DSC123 | Public Provider Profile | Guest views only basic public information about a Local Provider. Contact details and price remain hidden; public capacity and availability summary remain visible. | Must |
| Tour Agency | Discovery | DSC033 | Experience Detail | Displays the permitted Experience information and provides actions such as View Provider, View Village, Chat, and Request Quote. | Must |
| Guest | Discovery | DSC124 | Public Experience Detail | Guest views basic public Experience information. Restricted information and actions require Login. | Must |
| Tour Agency | Communication | COM048 | Chat | The main communication screen for real-time text-based negotiation and clarification with the Craft Village partner. | Must |
| Local Provider | Communication | COM065 | Chat | The main communication screen for real-time text-based negotiation and clarification with the Travel Agency partner. | Must |
| Tour Agency | Communication | COM125 | Attach Document | Allows Tour Agency to attach a document/file to a Chat message. | Should |
| Local Provider | Communication | COM126 | Attach Document | Allows Local Provider to attach a document/file to a Chat message. | Should |
| Tour Agency | Quote Request | — | Request Quote - Action | Not a separate screen. The Request Quote button opens Chat and automatically sends the initial quote-request message. The same Experience/activity can trigger the request only once. | — |
| Local Provider | Dashboard | DSH018 | Local Provider Dashboard | Main entry point after Local Provider login, providing an overview of Experiences, bookings, schedule, conversations, and pending actions. | Must |
| Local Provider | Profile Management | PRF127 | Provider Profile | Profile of the current Local Provider, including business information, description, contact information, Experiences, and its associated Village. The Village name links to Village Profile. | Must |
| Local Provider | Profile Management | PRF128 | Edit Provider Profile | Allows a Local Provider to edit its own business information. Uses the same field structure as Provider Profile, with inline AI Refine for the description. | Must |
| Tour Agency | Profile Management | PRF019 | Agency Profile | Company profile containing company information, tour preferences/characteristics, and contact information. Agency users can view it, but only the authorized highest-level Agency user can edit it. Local Providers see only permitted information. | Must |
| Tour Agency | Profile Management | PRF021 | Edit Agency Profile | Allows the authorized highest-level Agency user to edit company information, tour preferences/characteristics, and contact information. | Must |
| All Authenticated Users | Account Management | ACC129 | My Account | Displays the current user's personal account information, role, and associated business/Village. The avatar menu provides My Account, My Business where applicable, and Logout. | Must |
| All Authenticated Users | Account Management | ACC130 | Edit My Account | Allows the user to edit permitted personal account information. Business information is managed separately through My Business. | Must |
| All Authenticated Users | Navigation | — | Account Dropdown | Not a separate screen. Shared global component opened from the avatar. Contains My Account, My Business where applicable, and Logout. | — |
| Tour Agency / Local Provider / Admin | Village Discovery | VIL030 | Village Profile | View-only Village profile containing Village information, Local Provider cards belonging to the Village, and featured Experiences. Provider cards link to Provider Profile; Experience cards link to Experience Detail. | Must |
| Local Provider | Experience Management | EXP067 | Experience Management | Lists the Experiences belonging to the current Local Provider and supports viewing, creating, updating and deleting/archiving Experiences; no Draft/Publish/Listed lifecycle. | Must |
| Local Provider | Experience Management | EXP069 | Add Experience | Creates a new Experience with required information such as description, images, price, capacity, availability, and booking conditions. | Must |
| Local Provider | Experience Management | EXP068 | Experience Detail – Owner View | Displays the full Experience information belonging to the current Local Provider before editing or managing it. | Must |
| Local Provider | Experience Management | EXP070 | Edit Experience | Allows the Local Provider to edit its own Experience. AI Refine is available inline within the Description field. | Must |
| Local Provider | Experience Management | EXP132 | Delete Experience Confirmation | Confirms delete/archive: active references block; historical references archive; no references permits hard delete. | Must |
| Local Provider | Booking Management | BKG133 | Booking Management | Lists the Local Provider's bookings by status and highlights bookings requiring action. | Must |
| Local Provider | Booking Management | BKG134 | Create Booking | After the Agency and Local Provider agree through Chat, the Local Provider creates a booking containing the Experience, date/time, group information, capacity, and agreed conditions. | Must |
| Local Provider | Booking Management | BKG135 | Booking Detail | Displays booking details, status, Experience, arrival schedule, and relevant collaboration information. | Must |
| Local Provider | Booking Management | BKG144 | Edit Booking Detail | Allows authorized users to update booking details and status. Status uses permitted On hold/Booked/Cancelled transitions; Completed is reached only through F-SCHED-06. | Must |
| Local Provider | Booking Management | BKG136 | Confirm Group Arrival | Allows the Local Provider to confirm group arrival and update the booking progress/status. | Must |
| Tour Agency | Booking Management | BKG137 | Booking History | Lists the Agency's bookings by status, On hold, Booked, Completed and Cancelled. | Must |
| Tour Agency | Booking Management | BKG138 | Booking Detail | Displays the Agency's booking details and the current collaboration status with the Local Provider. | Must |
| Local Provider | Schedule | SCH139 | Provider Schedule | Local Provider's schedule showing booked/on-hold time slots for availability management. Other Agencies' identities and booking details are not exposed. | Must |
| Tour Agency | Schedule | SCH140 | Provider Schedule – Agency View | Logged-in Agency views a Local Provider's public schedule. Calculated operating windows and anonymous Booked/On hold occupancy are shown; other Agencies and their booking details remain hidden. | Must |
| Tour Agency | Schedule | SCH141 | Agency Schedule | Private Agency schedule showing the Agency's own bookings and collaboration details. It is synchronized after every booking event, including new On hold creation. | Must |
